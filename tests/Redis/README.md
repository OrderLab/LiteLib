# LiteSys for Redis

We have 3 setups for Redis experiments:
- Vanilla Redis service with instant rebooting
	- Node 2: YCSB Client
	- Node 3: Vanilla Redis Service:16379
- Redis service with a Replica and three Sentinel instances
	- Node 2: YCSB Client
	- Node 3: Master Redis Service:16379
	- Node 1: Redis Replica:16379
	- Node 1/2/3: Redis Sentinels:26479
- Redis service with LiteSys
	- Node 2: YCSB Client
	- Node 3: Master Redis Service:/tmp/redis.sock, Redis LiteSys:6479

Automatic scripts are provided for experiments.

```sh
# Under the scripts directory
# Step 1. Set up the experiment environment
./setup-experiment.sh [vanilla, replica, read-only-replica, lite]
# Step 2. Run the experiment
./run-experiment.sh [vanilla, replica, read-only-replica, lite]
```

Configurations of Redis instances and YCSB workload are under `config`. Python scripts for performance monitoring can be found at `monitor`. Logs generated by Redis instances, scripts and clients are under `logs`, while performance data are collected at `data`.

To build the Redis LiteSys from source, use CMake at `src/lite-version/build`, or using the `setup-experiment.sh` to build automatically.

Scripts for experiments in Docker containers can be found at `container-tests`.
